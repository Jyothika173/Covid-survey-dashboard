# COVID-19 Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze COVID-19 trends, including cases, deaths, recoveries, and country-wise performance.

## Features
- Global COVID-19 overview
- Country-wise analysis
- Trend visualization
- Interactive filtering and drill-down
- Key KPI cards

## Tools Used
- Power BI Desktop
- Power Query
- DAX
